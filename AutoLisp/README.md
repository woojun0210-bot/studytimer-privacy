# AutoLisp

CAD 작업을 빠르게 해 주는 AutoLISP 도구 모음입니다.
출력(Plot), 문자 찾기/바꾸기, 자동 정리(Purge), 수량 산출, MTEXT 변환 기능이 들어 있습니다.

AutoLISP로 작성되어 **AutoCAD, GstarCAD, ZWCAD, BricsCAD** 등 AutoLISP를 지원하는 CAD에서 같은 파일로 동작합니다.

## 설치

1. `dist/AutoLisp.lsp` 파일을 원하는 폴더에 복사합니다.
2. CAD에서 `APPLOAD` 명령으로 파일을 불러옵니다.
3. 도면을 열 때마다 자동으로 불러오려면 `APPLOAD` 창의 **시작하기(Startup Suite / 내용)** 에 파일을 추가합니다.
4. `ALHELP` 를 입력하면 명령어 목록이 나옵니다.

> 한글이 깨져 보이면 (AutoCAD 2021 이상에서 `LISPSYS` 가 1인 경우 등) `dist/AutoLisp_UTF8.lsp` 를 대신 사용하세요.

## 명령어

| 명령어 | 기능 |
|---|---|
| `ALPLOT` | 도곽 일괄 출력. 도곽 **블록** / 도곽 **사각형 폴리선** / **창 지정** 중 선택, 좌→우 또는 위→아래 순서 정렬, PDF 장치를 고르면 장별 PDF 파일로 저장 |
| `ALPLOTL` | 레이아웃 일괄 출력 (`1,3-5` 처럼 번호 선택). 각 레이아웃의 페이지 설정대로 출력, PDF 장치면 파일로 저장 |
| `ALFTE` (`ALFIND`, `ALFR`) | 문자 찾기/바꾸기 대화상자. 아래 [찾기/바꾸기](#찾기바꾸기-alfte) 참고 |
| `-ALFIND`, `-ALFR` | 대화상자 없이 명령행으로 찾기/바꾸기 (스크립트용) |
| `ALPURGE` | 사용하지 않는 블록·레이어·선종류·스타일 등 소거 (3회 반복) + 빈 문자, 길이 0 객체 삭제 |
| `ALAUTOPURGE` | 저장할 때마다 자동 소거 켜기/끄기 (설정은 저장되어 다음에도 유지) |
| `ALQTY` | 수량 산출. 레이어 / 객체 종류 / 레이어+종류 별 개수, 길이(m), 면적(m²). 도면 단위 mm·cm·m 선택 |
| `ALBCNT` | 블록 이름별 개수 (동적 블록은 원래 이름으로 집계) |
| `ALTSUM` | 선택한 문자·치수의 숫자 합계/평균 (`L=1,234.5` 같은 문자에서도 숫자를 읽음), 결과를 도면에 쓰기 |
| `ALT2M` | TEXT → MTEXT. 여러 줄을 하나의 MTEXT로 합치기(줄 간격 유지) 또는 각각 변환 |
| `ALM2T` | MTEXT → TEXT. 줄마다 TEXT 하나씩 만들고 서식 코드는 제거 |
| `ALMCLEAN` | MTEXT 의 글꼴·색·높이 등 서식 코드 제거 (줄바꿈은 유지) |
| `ALHELP` | 명령어 목록 |

## 찾기/바꾸기 (`ALFTE`)

`ALFTE`, `ALFIND`, `ALFR` 중 아무거나 입력하면 대화상자가 열립니다.

**검색 위치**: 전체 도면(모형+배치) / 현재 공간 / 모형 / 배치 / 객체 선택

**찾기**
- 도면 문자를 클릭해 내용 가져오기(`선택<`), 여러 문자를 선택해 한 번에 찾기(`여러 개<`)
- 최근 찾은 내용 15개 기억
- 전체 내용 일치, 쉼표로 여러 문자 찾기, 대소문자 구분
- 결과 목록 더블 클릭 → 확대 (+ 문자 영역에 빨간 가상 사각형)
- 결과 처리: 선택 항목/전체를 도면에서 선택, 연결선 그리기, 삭제, 목록에서 제거

**바꾸기**
- 찾을 문자 → 바꿀 문자 목록을 여러 개 만들어 한 번에 실행
- 목록 가져오기: 직접 입력 / 텍스트 파일(구분 문자 지정) / 엑셀에서 선택한 두 열
- 목록 저장·불러오기 (20개까지, `%APPDATA%\AutoLisp\FTE` 에 저장)
- 잠긴 레이어의 문자도 잠금을 잠시 풀어서 바꾸고 다시 잠급니다
- 블록 정의 안의 문자는 한 번만 바꾸며 같은 블록 전체에 반영됩니다

**찾기 패턴**

| 입력 | 의미 | 예 |
|---|---|---|
| `가나다(?!하하)` | 바로 뒤에 `하하` 가 오는 것은 제외 (`\|` 로 여러 개) | `가나다(?!하하\|호호)` |
| `*` | 아무 문자 여러 개 (와일드카드 사용 시) | `가나다*` → `XXX` 이면 `가나다하하` 전체가 `XXX` |
| `#` | 숫자 한 개 (와일드카드 사용 시) | `x###x` → `x150x` 이면 `1x200x3` → `1x150x3` |
| `{*}` | 이 부분만 바꿀 문자로 치환 (와일드카드 사용 시) | `가나다{*}` → `XXX` 이면 `가나다하하` → `가나다XXX` |

**검색 설정** (`검색 설정 / 찾은 문자 처리...` 버튼)
- 대상: TEXT, MTEXT, 블록 속성·속성 정의, 블록 내부 문자, 치수(재지정 문자), 다중 지시선, 표
- 동일 블록은 결과에 하나로, 띄어쓰기 무시(찾기/바꾸기 따로), 꺼진·동결 레이어 제외(찾기/바꾸기 따로), 와일드카드, Zoom 단계, 가상 사각형
- 찾은 문자 처리: 없음 / 삭제 / 특성 변경(높이, 폭 비율, 색상, 문자 스타일, 레이어)

**MTEXT 서식**: 와일드카드·전체 일치·띄어쓰기 무시·제외 조건을 쓰지 않으면 서식(글꼴, 색 등)을 유지한 채 바꿉니다. 이 옵션들을 쓰면 줄바꿈은 유지되고 서식은 지워집니다.

**아직 없는 것**: 여러 도면 파일에서 찾기/바꾸기 (5단계에서 추가 예정)

`ALQTY`, `ALBCNT` 결과는 명령행에 표로 보여 주고, **도면에 표 그리기** 또는 **CSV 파일(엑셀)** 로 내보낼 수 있습니다.
마지막에 고른 장치·용지·단위 등은 기억되어 다음 실행 때 기본값이 됩니다.

## CAD 별 지원 범위

| 기능 | Windows 용 AutoCAD / GstarCAD / ZWCAD / BricsCAD | AutoCAD LT 2024+, Mac 용 AutoCAD |
|---|---|---|
| 찾기/바꾸기, 소거, 수량, 문자 변환 | 사용 가능 | 대부분 사용 가능 (다중 지시선, 해치 면적 제외) |
| 출력(`ALPLOT`, `ALPLOTL`), 자동 소거 | 사용 가능 | 사용 불가 (ActiveX 미지원) |

## 알아 둘 점

- `ALPLOT` 은 현재 공간(모형 또는 레이아웃)의 페이지 설정을 바꿔서 출력합니다.
- `ALFR` 은 MTEXT 안에서 서식이 섞인 부분(예: 글자 중간에 글꼴이 바뀐 경우)은 찾지 못할 수 있습니다. 먼저 `ALMCLEAN` 으로 서식을 지우면 확실합니다.
- `ALM2T` 는 줄바꿈(Enter) 기준으로 나눕니다. 폭에 맞춰 자동 줄바꿈된 문단은 한 줄로 만들어집니다.
- 문자 변환은 평면(XY) 상의 문자를 기준으로 합니다.
- 실행한 작업은 `U`(실행 취소) 한 번으로 되돌릴 수 있습니다.

## 개발

```
AutoLisp/
├─ src/        소스 (기능별 .lsp, 대화상자 .dcl)
├─ dist/       배포 파일 (build.py 로 생성)
├─ tests/      문자열 처리 함수 테스트
└─ build.py    src → dist 합치기 + 괄호 검사
```

- 수정은 `src/` 에서 하고 `python build.py` 로 `dist/` 를 다시 만듭니다.
- 테스트: `python tests/test_string.py`, `test_match.py`, `test_fte.py`, `test_dcl.py`
  - CAD 없이 돌아가는 간이 AutoLISP 인터프리터(`tests/minilisp.py`)와 가짜 도면(`tests/fakecad.py`)으로
    문자열 처리, 찾기 패턴, 찾기/바꾸기 엔진, 대화상자 정의를 검증합니다.
  - 화면 확대, 대화상자 표시, 출력 같은 실제 CAD 동작은 CAD에서 확인해야 합니다.
